# Starr-Chem-test

## Launch Day 1

Open `astarryia-day1-foundation-reset.html` in a modern browser. This is the
canonical learner-facing entry point for AStarryia's Day 1 Math and Chemistry
Foundation Reset.

The frozen Day 1 content and interaction authorities are stored in
`Day1_Curriculum.md`, `Day1_Interactive_Layer_Specification.md`, and
`Math_Gym_Specification.md`. The standalone molecule workbench is available as
`molecule-stage.html`; the canonical learner session integrates the same
verification logic through `molecule-stage.js`.

## Manual verification still required
