# U1-03 Functional Groups - Cold Item Instantiation

**Status:** normative companion to `UNIT1_LESSON_U1_03_FUNCTIONAL_GROUPS_SCRIPT.md`.

This file exists to make the generic molecule set in **FG-I8** concrete before implementation. It does not change the lesson's chemistry, scoring contract, or teaching sequence.

## FG-I8 required held-out molecule pairs

Use exactly these four molecular identities for the first production item bank unless a later audited content revision replaces them:

1. **Alcohol pair:** 3-hexanol
2. **Ether pair:** 1-ethoxybutane
3. **Ketone pair:** 2-hexanone
4. **Amide pair:** N-ethylpropanamide

For each identity, generate two drawings that preserve **exactly the same atom connectivity and bond order** while changing page orientation or drawing layout.

The second rendering may rotate, mirror the page layout where chemically appropriate, or redraw the carbon skeleton, but it may not:
- break or reconnect a bond,
- move a substituent onto a different atom,
- change a single bond to a double bond or vice versa,
- change the functional-group identity,
- use stereochemical wedges/dashes to introduce a new stereochemical question.

## Hold-out protection

These four molecular identities are reserved for FG-I8 cold evidence. They may not appear as concrete examples in:
- Teach / Watch,
- Build Together,
- Guided,
- misconception repair,
- IDK worked examples,
- toolbox examples,
- test-out practice before the cold item.

If one is accidentally exposed with answer-revealing support, that exact molecule is contaminated for cold evidence and must be replaced by a newly audited held-out molecule.

## FG-I8 scoring relationship

The scoring contract in the main U1-03 script remains authoritative. In addition, the implementation must verify for every pair that:

1. the learner identifies the same functional-group class in both drawings,
2. the learner points to the same role-preserving local pattern in both drawings,
3. the learner explains that page orientation/layout changed while connectivity did not,
4. a response that says the functional group changed because an atom moved left/right/up/down fails,
5. a correct class label paired with a connectivity reversal does not create explanation evidence.
