# UNIT 1 LESSON U1-07 - ALKANE NAMING FROM STRUCTURE
## Fully authored beginner lesson script

**Status:** content draft for instructional review before runtime implementation.

**Parent curriculum:** `UNIT1_BEGINNER_TEACHING_CURRICULUM.md`

**Teaching-engine contract:** `DR_MERISSA_TEACHING_ENGINE_SPEC.md`

**Frozen template standards:** U1-01, U1-03, U1-04, U1-05, U1-10, U1-11, U1-12, U1-13.

**Purpose:** teach basic acyclic alkane IUPAC naming as a reversible set of structural instructions: choose the correct parent chain, number it by the lowest-locant rule, identify substituents, alphabetize different substituent names, use multiplicative prefixes correctly, format the name, and reverse-check by rebuilding the structure.

Cold items carry role-preserving scoring contracts from the start.

---

# 1. LESSON GOAL

A beginner should leave able to:

1. read every carbon in a bond-line/condensed alkane,
2. distinguish a continuous carbon path from the straightest-looking path,
3. choose the longest valid parent chain in the introductory acyclic alkane scope,
4. number the parent from the end that gives the **lowest set of substituent locants at the first point of difference**,
5. identify simple alkyl substituents such as methyl and ethyl,
6. recognize repeated identical substituents and use `di-`, `tri-`, etc.,
7. alphabetize different substituent names while ignoring multiplicative prefixes such as `di-` and `tri-` for alphabetization,
8. use commas between numbers and hyphens between numbers and words,
9. name a fresh branched alkane,
10. rebuild a fresh structure from a name,
11. explain why a tempting alternate name is wrong.

The lesson is not complete because the learner can recognize a memorized shape. It is complete when she can reconstruct the naming decisions in order.

---

# 2. SCOPE BOUNDARY

This lesson covers **basic acyclic alkane nomenclature** needed for Unit 1.

Do not silently expand into:
- alkene/alkyne suffix rules,
- cycloalkane parent-selection rules,
- alcohol/amine priority nomenclature,
- stereochemical R/S or E/Z descriptors,
- complex substituent naming,
- obscure tie cases not verified in current course material.

If later course materials require additional Chapter 4 naming rules, add them explicitly rather than pretending this introductory lesson already covers them.

# 3. ORIENTATION

## Screen title

**IUPAC names are directions for rebuilding a structure**

Dr. Merissa:

> "A good chemical name is not a nickname for a picture. It tells another chemist which carbon chain is the parent, where the branches are, and what those branches are. If the name is correct, we should be able to rebuild the same structure from it."

Immediate check:

Show the same five-carbon skeleton bent two different ways on the page.

Prompt:
**If no bonds were broken, should the correct name change just because the drawing was bent differently?**

Correct: **No**.

# 4. SMALLEST PREREQUISITE GATE

## P1 - count bond-line carbons

Show a short zigzag and ask learner to count line ends + vertices.

If missed, route to U1-01 micro-repair.

## P2 - continuous path

Show a branched carbon skeleton with one highlighted candidate path.

Prompt:
**Can a parent chain turn at a branch, or must it look like one straight line across the page?**

Correct: **It may turn; it only has to be continuous without jumping/reusing a carbon.**

## P3 - carbon root names needed here

Check only the roots that appear in this lesson:
- 4 butane,
- 5 pentane,
- 6 hexane,
- 7 heptane,
- 8 octane.

If not known, provide a compact root card. Do not turn the gate into a memorization exam.

# 5. TEACHING SEQUENCE - I DO

## WATCH 1 - Parent chain means longest continuous carbon path

Use a branched six-carbon example drawn so the longest path bends upward and is **not** the visually straight horizontal route.

Trace several candidate paths one at a time.

Dr. Merissa:

> "Ignore what looks straight. A carbon path can turn. Count the actual connected carbons. The parent is the longest valid continuous path in the scope we are using."

Prediction:
**Which highlighted path contains more connected carbons?**

Do not name substituents yet.

---

## WATCH 2 - Worked example: 2-methylpentane

Use `CH3-CH(CH3)-CH2-CH2-CH3`.

### Step A: choose parent

Longest chain = 5 -> `pentane`.

### Step B: number from both ends

From left, methyl = C2.
From right, methyl = C4.

Prompt before reveal:
**Which numbering gives the branch the lower locant?**

Correct: left -> `2`.

### Step C: name branch

One-carbon branch = methyl.

### Step D: assemble

`2-methylpentane`.

### Step E: reverse-check

Clear structure. Start with pentane, number 1-5, attach methyl at C2. Confirm original connectivity returns.

---

## WATCH 3 - Repeated substituents

Use **2,3-dimethylpentane**.

Show two methyl branches.

Dr. Merissa:

> "When the same substituent appears more than once, keep every locant and use a multiplicative prefix. Two methyl groups become dimethyl. The prefix tells quantity; it does not erase the individual positions."

Correct assembly:
`2,3-dimethylpentane`.

Formatting:
- comma between `2,3`,
- hyphen between `3` and `dimethyl`,
- no spaces inside the IUPAC name.

---

## WATCH 4 - Lowest set at the first point of difference

Show a parent chain with substituent locant options:
- direction A -> `2,4`
- direction B -> `3,5`

Dr. Merissa:

> "Compare the locant lists from the first number onward. At the first place they differ, choose the lower number. Here 2 beats 3, so 2,4 wins."

Do not teach `add the locants and choose the smaller sum`; that shortcut can fail.

---

## WATCH 5 - Different substituents and alphabetization

Use **3-ethyl-2-methylhexane**.

First establish the same six-carbon parent and the correct locants `2` and `3`.

Then identify:
- ethyl at 3,
- methyl at 2.

Dr. Merissa:

> "After the parent and locants are correct, list different substituent names alphabetically. Alphabetical order does not mean lowest locant first in the written name. Ethyl begins with E, so it is written before methyl even though its locant is 3."

Correct:
`3-ethyl-2-methylhexane`.

---

## WATCH 6 - Multiplicative prefixes do not control alphabetization

Show a controlled name assembly with ethyl + two methyl substituents.

Explain:
- alphabetize by `ethyl` versus `methyl`,
- ignore `di-` when deciding where `dimethyl` belongs alphabetically.

Do not introduce complex substituent alphabetization.

---

# 6. QUICK CONCEPT CHECK

Supported only.

1. Longest chain must look straight. **False**.
2. A parent chain may turn through the drawing. **True**.
3. Number from the left by default. **False**.
4. Compare numbering by lowest set at first point of difference. **True**.
5. Two methyl groups need both locants. **True**.
6. `di-` decides alphabetization before ethyl. **False**.
7. A correct name should rebuild the same connectivity. **True**.

Any miss returns only to the relevant relationship.

# 8. GUIDED PRACTICE

## Guided A - longest path trap

Use a branched skeleton where a six-carbon parent bends through the drawing and a five-carbon horizontal path looks visually longer.

Learner must trace parent before naming.

## Guided B - numbering

Use a hexane parent giving substituent choices `2,4` versus `3,5`.

Require learner to state the first point of difference.

## Guided C - alphabetization

Use **3-ethyl-2-methylhexane** only if it was not already used as the completed Watch molecule; because Watch uses it, Guided must instead use a different supported example such as **4-ethyl-2-methylheptane**.

Learner places ethyl before methyl in the written name.

## Guided D - name to structure

Use **2,4-dimethylhexane** as a support-only reconstruction example. Because that exact identity is support-used here, it is forbidden from the cold bank.

### Scaffold fading

After two consecutive correct guided decisions:
1. remove candidate-path highlights,
2. remove automatic carbon numbering,
3. remove root-name card,
4. remove alphabetical-order reminder,
5. reduce task to `parent -> number -> substituents -> assemble -> reverse-check`,
6. hints learner-requested only.

Guided remains supported even after fading.

---

# 9. MISCONCEPTION CONTRASTS

## M1 - straightest = longest

Switch representation to a graph of carbon nodes/edges; trace paths independent of page orientation.

## M2 - always number left to right

Rotate the same molecule 180 degrees on screen; show chemistry unchanged while visual left/right swaps.

## M3 - choose branches before parent

Show how calling a carbon a `branch` too early changes when a longer parent is found. Parent first.

## M4 - add locants and pick smaller total

Show two hypothetical locant sets where sums could tempt a wrong shortcut. State authoritative rule: compare ordered locant sets at first point of difference.

## M5 - alphabetical order means smallest locant first

Contrast `3-ethyl-2-methyl...` with the incorrect `2-methyl-3-ethyl...` when writing substituent order.

## M6 - di/tri alphabetize under D/T

Strip multiplicative prefix visually and alphabetize by the substituent name.

## M7 - repeated substituent needs one locant

Show two methyl branches and force one-to-one locant tagging.

## M8 - redraw means new name

Rotate/bend identical connectivity; name remains unchanged.

# 10. SIX IDK ROUTES

1. **Question meaning:** identify whether task is `find parent`, `number`, `name branch`, `assemble`, or `rebuild`.
2. **Don't know how to start:** circle/trace all carbon paths; do parent only.
3. **Forgot prerequisite:** targeted U1-01 carbon-count or root-name micro-review.
4. **Started but stuck:** preserve work and repair only parent/number/substituent/alphabetization/formatting step.
5. **Need example:** use a support-only molecule not in the cold reservation list; model one naming pass, then fresh item.
6. **Explanation not making sense:** switch to **Carbon-Path Map Mode**, displaying the molecule as numbered carbon nodes connected by edges before re-rendering as bond-line.

Any IDK support contaminates the current independent item; recollect on a fresh one.

## NAM-I1 - simple branch

Use **3-methylhexane**.

Prompt: **Name the molecule and explain parent length and substituent position.**

Required:
1. six-carbon longest chain -> hexane,
2. methyl substituent,
3. locant 3 from either equivalent numbering direction,
4. `3-methylhexane`.

Wrong-but-keyword-complete failure:
> "3-ethylpentane because the straight-looking five-carbon line is the parent and the remaining two carbons form ethyl."

Why fails: misses the longer continuous six-carbon path.

---

## NAM-I2 - repeated substituents

Use **2,2-dimethylhexane**.

Required:
- hexane parent,
- two methyls both at C2,
- `2,2-dimethylhexane`,
- comma/hyphen structure correct.

Wrong:
> "2-methyl-2-methylhexane because each branch should be written separately without di-."

Why fails: valid locants are recognized but repeated-substituent assembly rule is not.

---

## NAM-I3 - alphabetization + numbering

Use **3-ethyl-2-methylheptane**.

Required:
1. heptane parent,
2. locants 2 and 3 under correct numbering,
3. ethyl at 3, methyl at 2,
4. ethyl written before methyl alphabetically,
5. exact name.

Wrong-but-keyword-complete:
> "2-methyl-3-ethylheptane because substituents must be written in locant order."

Why fails: locants may be correct but written substituent order is not alphabetical.

---

## NAM-I4 - visually nonstraight parent

Use exact condensed connectivity:
`CH3CH2CH(CH2CH2CH3)CH2CH3`.

Render so the apparent horizontal route is not the longest.

Expected name: **3-ethylhexane**.

Required:
1. longest path contains six carbons,
2. remaining two-carbon branch is ethyl,
3. numbering gives branch C3 rather than C4,
4. name `3-ethylhexane`.

Wrong:
> "3-propylpentane because the horizontal five-carbon path is the parent."

Why fails: chooses visual straightness over longest connectivity.

---

## NAM-I5 - name to structure

Prompt: **Draw/rebuild 2,2,4-trimethylpentane from the name, then identify the parent and branch carbons.**

Required:
- five-carbon parent,
- methyls at 2,2,4,
- total carbon count 8,
- normal carbon valence.

Wrong-but-keyword-complete:
A drawing with methyls at 2,4,4 must fail even though it contains pentane + three methyl groups.

Why fails: locant roles changed.

---

## NAM-I6 - multiple different/repeated substituents

Use a held-out structure whose correct name is **4-ethyl-2,2-dimethylheptane**.

Required:
- heptane parent,
- ethyl C4,
- two methyls C2,C2,
- alphabetize ethyl before methyl, ignoring `di-`,
- exact formatting.

Wrong:
> "2,2-dimethyl-4-ethylheptane because dimethyl begins with D before ethyl."

Why fails: multiplicative prefix `di-` is ignored for alphabetization.

---

## NAM-I7 - numbering direction

Use a new held-out heptane skeleton that yields locant sets **2,4** from one end and **4,6** from the other; do not reuse Guided's geometry.

Prompt: **Choose numbering and explain the first point of difference.**

Required:
- compare ordered sets,
- choose 2,4 because 2 < 4 at first difference,
- no `sum of locants` justification required or accepted as sole rule.

Wrong:
> "Either direction is acceptable because both have two substituents."

---

## NAM-I8 - full test-style naming

Use a held-out structure with an **octane** parent, methyl substituents at `2,6`, and an ethyl substituent at `4`, constructed so no longer parent exists.

Correct name:
**4-ethyl-2,6-dimethyloctane**.

Required:
1. octane parent,
2. correct numbering locants 2,4,6,
3. ethyl at 4, methyl at 2 and 6,
4. `dimethyl` quantity correct,
5. alphabetize ethyl before methyl,
6. correct punctuation,
7. reverse-check rebuilds same connectivity.

Wrong-but-keyword-complete:
> "2,6-dimethyl-4-ethyloctane."

Why fails: connectivity information is present, but substituent writing order violates alphabetization.

Contradiction rule:
Correct final text with an explanation claiming the shorter visible chain is the parent does not earn explanation evidence.

# 13. EXPLAIN-WHY

E-W1: Why can the longest chain bend? -> continuity is connectivity, not page straightness.

E-W2: Why number one direction over the other? -> lowest ordered locant set at first point of difference.

E-W3: Why is `3-ethyl-2-methylhexane` written ethyl first? -> alphabetize substituent names, not locants.

E-W4: Why ignore `di-` for alphabetization? -> prefix reports quantity; base substituent name controls alphabetical position in this scope.

E-W5: Why reverse-check? -> a valid name must reconstruct the intended connectivity.

Each explanation rejects role-reversed versions.

1. Rotate/redraw a named molecule and verify name unchanged.
2. Give a correct name and one near-miss; diagnose whether error is parent, numbering, alphabetization, or formatting.
3. Name -> structure -> name round trip.
4. Compare two candidate parent paths explicitly by carbon count rather than appearance.
